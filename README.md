# App de Tareas

Página pequeña para gestionar tareas con:

- Header con nombre editable (se guarda en localStorage) y reloj.
- Botón para cambiar a modo oscuro (persistente).
- Botón flotante (+) para crear tareas en modal.
- Modal con título, descripción, subtareas (creables), color (6 pasteles), fecha, duración y estado.
- Vista central: tarjetas de tareas, máximo 5 por fila (se ajusta en móvil).
- Indicador de subtareas en la esquina inferior derecha de cada tarjeta.
- Filtros para ver todas/completadas/en progreso/sin iniciar.
- Footer con progreso en formato X/Y y barra de progreso.

Uso:

1. Abrir `index.html` en el navegador.
2. Hacer click en el nombre para editar y pulsar Enter o hacer click fuera para guardar.
3. Pulsar + para crear tareas.

Archivos:
- `index.html`
- `styles.css`
- `app.js`

Puedes pedir mejoras: editar tareas, eliminar, arrastrar, notificaciones, etc.
